# Публикация в Google Play Store

## Требования

- Android Studio (последняя стабильная версия)
- JDK 17+
- Аккаунт Google Play Console (25$ единоразово)

---

## Шаг 1: Генерация подписного ключа (keystore)

Выполните в терминале:

```bash
keytool -genkey -v \
  -keystore point-release.jks \
  -alias point-key \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000
```

> **Важно:** Храните файл `point-release.jks` и пароли в безопасном месте.
> Потеря ключа = невозможность обновлять приложение навсегда.

---

## Шаг 2: Настройка подписи

1. Скопируйте шаблон: `cp keystore.properties.template keystore.properties`
2. Заполните `keystore.properties`:
   ```
   storeFile=../point-release.jks
   storePassword=ВАШ_ПАРОЛЬ_ХРАНИЛИЩА
   keyAlias=point-key
   keyPassword=ВАШ_ПАРОЛЬ_КЛЮЧА
   ```
3. Убедитесь, что `keystore.properties` и `*.jks` добавлены в `.gitignore` (уже сделано).

---

## Шаг 3: Сборка release AAB

```bash
./gradlew bundleRelease
```

Файл будет создан по пути:
`app/build/outputs/bundle/release/app-release.aab`

---

## Шаг 4: Регистрация в Google Play Console

1. Перейдите на [play.google.com/console](https://play.google.com/console)
2. Создайте новое приложение
3. Заполните:
   - **Название:** Point — Классические Точки
   - **Краткое описание:** Классическая стратегия «Точки» для двух игроков
   - **Полное описание:** (см. ниже)
   - **Категория:** Настольные игры
   - **Email поддержки:** ваш email

---

## Шаг 5: Подготовка ассетов для Play Store

| Ресурс | Размер | Описание |
|--------|--------|----------|
| Иконка | 512×512 PNG | Иконка приложения |
| Скриншоты телефона | минимум 2 | 1080×1920 или аналог |
| Feature graphic | 1024×500 JPG/PNG | Баннер (опционально) |

---

## Шаг 6: Загрузка и публикация

1. В Play Console → **Выпуски** → **Production** → **Создать выпуск**
2. Загрузите `app-release.aab`
3. Заполните примечания к выпуску (например: "Первый выпуск")
4. Отправьте на проверку (обычно 1–3 дня)

---

## Описание для Play Store (RU)

**Краткое (80 символов):**
```
Классическая стратегия «Точки» — окружай и захватывай!
```

**Полное (4000 символов):**
```
Point — классическая стратегическая игра «Точки» для двух игроков на одном устройстве!

Правила просты:
• Два игрока по очереди ставят точки на сетке
• Окружите точки соперника своими — и захватите их
• Побеждает тот, кто захватит больше точек

Игра «Точки» — любимая классика на листке в клетку, теперь в цифровом формате!

Особенности:
✓ Честная игра — алгоритм честно определяет захваченные точки
✓ Удобное управление — просто нажмите на клетку
✓ Счётчик очков в реальном времени
✓ Игра для двух на одном устройстве
✓ Без рекламы, без интернета — играйте где угодно
```

## Политика конфиденциальности

Приложение не собирает никаких персональных данных. Если Play Store требует ссылку на политику конфиденциальности, используйте шаблон:

> «Point не собирает, не хранит и не передаёт никакие персональные данные пользователей.»

Разместите этот текст на любом доступном URL (например, GitHub Pages, Notion, Telegra.ph).
