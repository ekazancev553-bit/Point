## Полное описание (4000 символов макс.)
```
Point — это цифровое воплощение любимой классической игры «Точки», которую
все мы рисовали на листке в клетку. Теперь она у вас в телефоне!

🎮 КАК ИГРАТЬ
Два игрока по очереди ставят точки на сетке. Окружите точки соперника своими
точками — и они станут вашими пленниками! Побеждает тот, кто захватит больше
точек к концу партии.

📐 ПРАВИЛА ПРОСТЫ
• Нажмите на пересечение линий сетки, чтобы поставить точку
• Окружите группу точек соперника со всех сторон
• Окружённые точки захватываются и засчитываются вам в счёт
• Игра заканчивается, когда поле заполнено
• Побеждает игрок с наибольшим счётом

✨ ОСОБЕННОСТИ
✓ Честный алгоритм — захват определяется по правилам классической игры
✓ Удобное управление одним пальцем
✓ Счётчик очков в реальном времени
✓ Индикатор хода с цветовой маркировкой
✓ Игра для двух на одном устройстве — передавайте телефон друг другу
✓ Диалог правил — всегда под рукой
✓ Сетка 15×15 — оптимальный размер для мобильного экрана
✓ Без рекламы, без интернета, без лишних разрешений

🏆 ДЛЯ КОГО
Идеально для любителей классических настольных игр, стратегий и всех, кто
помнит «Точки» с уроков в школе. Играйте с другом, с ребёнком или с кем
угодно — правила понятны с первого взгляда, а глубина стратегии не даёт
заскучать!

📱 ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ
• Android 5.0 и выше
• Не требует интернета
• Не запрашивает личные данные
• Размер приложения — менее 5 МБ
```
