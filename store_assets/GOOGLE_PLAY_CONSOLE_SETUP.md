# Настройка Google Play Console
## Package name: `com.pointgame.classic`

---

## Часть 1: Подготовка аккаунта

### 1.1 Регистрация разработчика
1. Перейдите на [play.google.com/console](https://play.google.com/console)
2. Войдите в аккаунт Google
3. Нажмите **Начать работу**
4. Оплатите регистрационный взнос **$25** (единоразово, картой)
5. Заполните данные разработчика:
   - Тип аккаунта: **Физическое лицо** (или организация)
   - Имя разработчика: будет отображаться в Play Store
   - Контактный email

---

## Часть 2: Создание приложения

### 2.1 Новое приложение
1. Play Console → **Все приложения** → **Создать приложение**
2. Выберите язык по умолчанию: **Русский — ru**
3. Название: `Point — Точки: Классическая стратегия`
4. Тип: **Приложение**
5. Категория: **Игра**
6. Бесплатное/платное: **Бесплатное**
7. Согласитесь с политиками → **Создать приложение**

> После создания Package name `com.pointgame.classic` будет зафиксирован навсегда.

---

## Часть 3: Основной листинг магазина

Перейти: **Магазин → Основная информация о магазине**

### 3.1 Текстовые данные

**Название приложения** (≤50 симв.):
```
Point — Точки: Классическая стратегия
```

**Краткое описание** (≤80 симв.):
```
Классическая стратегия «Точки» — окружай и захватывай точки соперника!
```

**Полное описание** (≤4000 симв.) — скопировать из `store_listing_ru.md`

### 3.2 Графические материалы

| Элемент | Файл | Требования |
|---|---|---|
| Иконка приложения | `icon/icon_512x512.png` | PNG, 512×512, ≤1 МБ |
| Feature Graphic | `feature_graphic/feature_1024x500.png` | PNG/JPG, 1024×500 |
| Скриншоты (≥2) | `screenshots/screenshot_*.png` | PNG, 1080×1920 |

**Порядок загрузки скриншотов:**
1. `screenshot_1_menu.png` — Главное меню
2. `screenshot_2_game.png` — Игровое поле в процессе
3. `screenshot_3_gameover.png` — Экран победы
4. `screenshot_4_howtoplay.png` — Правила игры

### 3.3 Категория и теги
- **Категория:** Настольные игры
- **Теги** (до 5): `стратегия`, `два игрока`, `классика`, `точки`, `оффлайн`

## Часть 4: Настройки приложения

### 4.1 Политика конфиденциальности
Перейти: **Политика → Политика конфиденциальности**

Создайте публичную страницу с текстом:
```
Point не собирает, не хранит и не передаёт никакие персональные данные
пользователей. Приложение работает полностью в автономном режиме и не
требует интернет-соединения.
```

Бесплатные варианты хостинга:
- **GitHub Pages:** создайте `privacy.html` в репозитории
- **Telegra.ph:** telegra.ph → создать страницу
- **Notion:** создайте публичную страницу

Вставьте URL страницы в Play Console.

### 4.2 Целевая аудитория
Перейти: **Контент → Целевая аудитория и контент**
- Возраст: **Для всех** (13+)
- Привлекает детей: **Нет**

### 4.3 Рейтинг контента
Перейти: **Контент → Рейтинг контента**
1. Нажмите **Начать опросник**
2. Категория: **Утилиты / Продуктивность / Другое**
3. Ответьте **Нет** на все вопросы (игра без насилия, без азартных элементов)
4. Сохраните → будет присвоен рейтинг **"Для всех"** / **PEGI 3**

### 4.4 Объявления и покупки
Перейти: **Контент → Реклама**
- Содержит рекламу: **Нет**

Встроенные покупки: не настраиваются (приложение бесплатное без IAP).

## Часть 5: Настройка GitHub Secrets для CI/CD

Для автоматической публикации через GitHub Actions нужно добавить 4 секрета.

### 5.1 Секреты для подписи AAB

Перейти: GitHub репозиторий → **Settings → Secrets and variables → Actions → New repository secret**

#### KEYSTORE_BASE64
Конвертируйте keystore в Base64:
```bash
base64 -w 0 point-release.jks
```
Скопируйте вывод → создайте секрет `KEYSTORE_BASE64`

#### KEYSTORE_STORE_PASSWORD
Значение: `pointgame123`

#### KEYSTORE_KEY_ALIAS
Значение: `point-key`

#### KEYSTORE_KEY_PASSWORD
Значение: `pointgame123`

### 5.2 Сервисный аккаунт Google Play

Нужен для секрета `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON`.

**Шаг 1:** Google Cloud Console → [console.cloud.google.com](https://console.cloud.google.com)
1. Создайте новый проект (или выберите существующий)
2. Включите API: **Google Play Android Developer API**
   - APIs & Services → Library → найдите "Google Play Android Developer API" → Enable

**Шаг 2:** Создать сервисный аккаунт
1. IAM & Admin → Service Accounts → **Create Service Account**
2. Имя: `play-publisher`
3. Описание: `GitHub Actions Play Store publisher`
4. Нажмите **Create and Continue**
5. Роль: **Service Account User** → Continue → Done

**Шаг 3:** Создать JSON-ключ
1. Нажмите на созданный сервисный аккаунт
2. Вкладка **Keys** → Add Key → **Create new key** → JSON → Create
3. Скачается файл `*.json` — сохраните его безопасно!

**Шаг 4:** Привязать к Play Console
1. Play Console → **Настройки → API-доступ**
2. Нажмите **Связать с проектом Google Cloud** (выберите проект из шага 1)
3. В разделе "Сервисные аккаунты" найдите `play-publisher`
4. Нажмите **Предоставить доступ**
5. Роль: **Менеджер выпусков** (Release Manager)
6. Нажмите **Применить**

**Шаг 5:** Добавить секрет в GitHub
```bash
# Содержимое JSON-файла целиком вставить в секрет:
cat play-publisher-*.json
```
Создайте секрет `GOOGLE_PLAY_SERVICE_ACCOUNT_JSON` со всем содержимым JSON.

## Часть 6: Первый выпуск

### 6.1 Ручная загрузка (без CI/CD)
Перейти: **Выпуски → Production → Создать выпуск**

1. Нажмите **Продолжить** при предложении использовать Play App Signing
2. Загрузите файл `app-release.aab`
3. **Название выпуска:** `1.0.0`
4. **Примечания к выпуску** (скопировать):
   ```
   Первый выпуск классической игры «Точки» для двух игроков.
   • Игровое поле 15×15
   • Захват точек с помощью алгоритма окружения
   • Счётчик очков в реальном времени
   • Без рекламы и интернета
   ```
5. **Просмотреть выпуск** → проверить все предупреждения
6. **Начать выпуск в Production** → подтвердить

### 6.2 Автоматическая публикация через CI/CD
```bash
# Создать и запушить тег — запустит workflow автоматически
git tag v1.0.0
git push origin v1.0.0
```

Либо вручную: GitHub → Actions → **Build & Publish to Google Play** → **Run workflow**

## Часть 7: После публикации

### Сроки проверки
- Новое приложение: **2–7 рабочих дней** (обычно 1–3)
- Обновления существующего: **несколько часов**

### Где отслеживать статус
Play Console → **Выпуски → Production → Статус выпуска**

Возможные статусы:
| Статус | Значение |
|---|---|
| На проверке | Google проверяет приложение |
| Опубликовано | Доступно в Play Store |
| Отклонено | Нужно исправить нарушения политики |
| Предупреждение | Рекомендуется исправить, но не блокирует |

### Типичные причины отклонения
- Иконка или скриншоты не соответствуют содержимому приложения
- Политика конфиденциальности недоступна по URL
- Рейтинг контента не заполнен
- Нарушения политики Play Store
